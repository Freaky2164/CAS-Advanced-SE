# Ersetze MS SQL Server / MS Access durch PostgreSQL 18

## Das Problem

Die bisherige Datenhaltung mit MMSQL Express ist proprietär und entspricht nicht modernen Standard an Datenbanken.

## Berücksichtigte Optionen

- Neuere Version von MSSQL nutzen
- **MSSQL durch PostgreSQL ersetzen**

## Begründung

PostgreSQL erfüllt alle sicherheitsrelevanten Anforderungen wie RLS und Authentifizierung und führt durch seine Open Source Natur Herstellerunabhängigkeit ein, die zu langfristiger wart- und erweiterbarkeit führt. Der Wechsel auf einen einzigen DB-Dialekt stellt zusätzlich eine angenehme Alternative zu der bisherigen Lösung dar.
